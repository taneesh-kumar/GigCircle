## 3. Discovered Legacy Mismatches Handled in `schema.sql`

In `DatabaseMigrationRunner.java`, legacy databases contained outdated PostgreSQL check constraints on `jobs.status` (when `JobStatus` only had `OPEN` and `ACCEPTED`) and `notifications.type`.

`schema.sql` includes conditional constraint cleanup (`ALTER TABLE ... DROP CONSTRAINT IF EXISTS`) and defines updated `CHECK` constraints covering all active enum values.
